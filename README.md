# Adyasha Dash – Academic Website

Personal academic website of Dr. Adyasha Dash (ETH Zurich).

Static site built with plain HTML, CSS and JavaScript, no build step required.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Profile photo

The portrait is `assets/portrait.png`. Replace the file to change it.

## Deploy

Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
